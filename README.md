# Power-BI-Cost Analysis Dashboard
📌 Project Overview

This project presents an interactive Cost Analysis Dashboard built using Power BI.

The dashboard provides insights into total costs across different dimensions, including customers, customer types, products, countries, and time periods.

🎯 Project Objective

The main objective of this project is to analyze cost data and provide a clear overview of spending patterns to support better business decision-making.

🛠️ Tools Used
Power BI
Microsoft Excel
Data Cleaning
Data Analysis
Data Visualization
📈 Key Insights & Analysis

The dashboard analyzes:

Total Cost by Customer Country
Total Cost by Customer Type
Cost Trends by Year and Month
Top 5 Customers by Total Cost
Top 5 Products by Total Cost
Geographical Distribution of Customers and Costs
